# PSEUDO Y Landingpage

Scroll-driven B2B landing page for **PSEUDO Y**, a local-first table-transformation tool aimed primarily at Controllers and Finance teams in German mid-sized companies.

## Core proposition

> Die lokale Schutzschicht zwischen Excel und KI.

PSEUDO Y prepares CSV/XLSX data locally in the browser, lets the user transform selected columns, preview the result, and export the transformed dataset.

**Important:** the current MVP positioning explicitly states that PSEUDO Y does **not** automatically transmit transformed data to ChatGPT, Claude, Gemini, or other AI providers.

## Page grammar

**Chaptered editorial with live surface** following the Scroll Craft methodology: journey first, one emotional peak, multiple device families, a bespoke signature move, separate mobile composition, and reduced-motion fallbacks.

## Signature move

The Y section visually separates two routes:

- transformed working data continues toward export;
- original↔pseudonym information branches into a separate mapping path.

The intended peak is: **“Jetzt verstehe ich, was mit meinen Originalwerten passiert.”**

## Product boundaries

The landing page does not claim:

- automatic GDPR compliance;
- full anonymisation;
- automatic AI-provider transfer;
- finished encrypted mapping storage/re-identification until implemented;
- unlimited support for arbitrary complex XLSX workbooks.
