## PSEUDOY rule

Do not patch the current page into a ScrollCraft page. First establish a visually strong static composition, especially on iPhone, then add the scroll behavior. Mobile is a separate composition, not a compressed desktop layout.

For PSEUDOY the current creative direction is premium-minimal / editorial, predominantly white, restrained blue accents, generous whitespace, strong typography and a bespoke Y data-flow signature move. The page must work visually before copy quality is evaluated.
