# PSEUDO Y ScrollCraft preview report

## Status

Visual preview only. The current production `index.html` was deliberately left unchanged so the visual direction can be judged before replacement.

## Grammar

Custom grammar: **Editorial workbench**.

Why: PSEUDO Y is a working software surface, but the brand direction asks for editorial whitespace and calm premium composition. A pure live-surface grammar would remove too much of the marketing context; chaptered editorial would underplay the product itself. The custom grammar therefore defines its own bans and uses the product surface as the visual spine rather than mixing two existing grammars casually.
