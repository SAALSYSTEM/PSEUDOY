Das Problem

KI ist schnell.
Rohdaten sind sensibel.

Excel ist im Controlling schnell erstellt, aber nicht automatisch für externe Analyse- oder KI-Systeme geeignet. Namen, Kundennummern, Kostenstellen oder interne Bezeichnungen können mehr verraten als für die Analyse nötig ist.

PSEUDO Y verändert gezielt nur die Felder, die Sie schützen möchten. Region, Marge oder andere analytisch relevante Werte können bewusst unverändert bleiben.

FAQ

Fragen, bevor Daten fließen.

Werden meine Tabellen hochgeladen?
Die Browser-Version ist darauf ausgelegt, die eigentlichen Tabelleninhalte lokal zu verarbeiten.
Sendet PSEUDO Y Daten an ChatGPT oder Claude?
Nein. Im MVP gibt es keine automatische Weitergabe an KI-Anbieter.
Ist Pseudonymisierung dasselbe wie Anonymisierung?
Nein. Pseudonymisierte Daten können weiterhin personenbezogene Daten sein, wenn eine Zuordnung über zusätzliche Informationen möglich bleibt.
Gibt es einen kostenlosen Tarif?
Nein. Es gibt eine kostenlose Demo mit synthetischen Beispieldaten.
