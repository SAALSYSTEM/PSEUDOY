# Design System

## Direction
Premium-minimal, editorial B2B software. Layout takes inspiration from calm fintech/editorial systems without copying a specific site.

## Typography
- Headlines: system serif stack (Iowan/Palatino/Georgia)
- UI/body: system sans stack

No external webfont dependency in the MVP landing page.

## Palette
- Background: `#f6f5f1`
- Surface: `#fbfaf7`
- Ink: `#111213`
- Blue: `#1f63e9`
- Olive accent: `#8b9163`

## Motion system
1. Typewriter typography
2. Selective sensitive-field highlight
3. Sticky live-surface demo
4. Bespoke Y-flow separation
5. Horizontal transformation rail
6. Quiet local-first route

The same motion family is not used twice in a row.
